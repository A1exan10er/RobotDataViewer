# 机器人数据查看器

1. 双击 **viewer.html**，用桌面浏览器打开查看器。
2. 点击 **打开文件夹**，选择原始记录文件夹或包含多段记录的上级文件夹；也可以点击 **打开 TAR**，直接选择原始记录的 `.tar` 文件。
3. 在侧栏中选择记录，点击 **播放**。

可以直接选择 `local-data` 文件夹。原始 TAR 文件无需解压或预处理。所有数据只在本机读取，可完全离线使用。

查看头戴相机数据时，选择完整的导出文件夹（例如 **T1E1**）或其 TAR 文件。左右眼视角、腕部视角、触觉响应和轨迹会自动一起显示；请保留其中的 `umi` 子文件夹，无需整理或转换数据。

拖动时间轴定位；使用速度菜单调整播放速度，或点击上一帧、下一帧逐帧查看。空格键切换播放与暂停，左右方向键逐帧移动。各面板均可展开。轨迹面板支持拖动旋转、Shift 拖动平移、滚轮缩放。展开“记录信号”可查看数值通道。

每个**触觉响应**面板只显示一张响应图，保持传感器原始画面的方向。琥珀色至红色表示相对于第一帧的图像响应逐渐增强；白色表示未检测到响应。**弱–强**图例表示相对图像响应，并非实测力或压力。系统自动抑制背景噪声。点击面板的显示设置（滑块图标），可在 1～16 倍之间调整显示增益（默认 8 倍），或开启**显示全部变化**，查看包含细微差异和噪声的结果。播放或跳转时始终使用第一帧作为参考，持续的图像变化不会因时间推移被抹去。若触觉图像没有可检测到的变化，查看器不会凭空显示接触。原始记录不会被修改。

查看器会自动使用完整的原始相机时间戳，支持 ARX5 训练数据中有意少一行的时间戳文件。“估算对齐”表示原始和训练时间戳文件均无法为每个视频帧提供有效时间戳，此时使用视频自身的时间信息估算。未记录触觉数值数据时，仍可查看触觉响应图。

点击语言按钮切换中英文。随时可打开其他文件夹或 TAR 文件。

请使用较新的桌面 Firefox、Chrome 或 Edge 浏览器。无需安装插件或额外的视频解码器。开始播放或跳转后，查看器可能短暂显示“正在同步”，以填充解码缓冲区。直接打开压缩包目前支持未压缩的 `.tar` 文件。
