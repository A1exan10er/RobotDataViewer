# 机器人数据查看器

请先完整解压便携版 ZIP，再打开 viewer.html。分发给同事或客户时，请保留包内的许可声明和源码材料。数据文件夹或 TAR 请单独提供，查看器本身不包含录制数据。无需安装、服务器、Python 或网络连接，RGB 和触觉数据会并行准备并同步开始播放。

1. 双击 **viewer.html**，用桌面浏览器打开查看器。
2. 点击 **打开文件夹**，选择原始记录文件夹或包含多段记录的上级文件夹；也可以点击 **打开 TAR**，直接选择原始记录的 `.tar` 文件。
3. 在侧栏中选择记录，点击 **播放**。

可以直接选择 `local-data` 文件夹。原始 TAR 文件无需解压或预处理。所有数据只在本机读取，可完全离线使用。

查看头戴相机数据时，选择完整的导出文件夹（例如 **T1E1**）或其 TAR 文件。左右眼视角、腕部视角、触觉响应和轨迹会自动一起显示；请保留其中的 `umi` 子文件夹，无需整理或转换数据。

拖动时间轴定位；使用速度菜单调整播放速度，或点击上一帧、下一帧逐帧查看。空格键切换播放与暂停，左右方向键逐帧移动。各面板均可展开。轨迹面板支持拖动旋转、Shift 拖动平移、滚轮缩放。展开“记录信号”可查看数值通道。

点击一次**播放**，RGB 与触觉画面将在所有可用通道就绪后同时显示并同步播放。准备期间时间轴保持在所选位置；点击**暂停**可取消等待中的播放请求。跳转和逐帧操作仍可使用，并会更新所有通道需要准备的位置。准备失败的通道会显示提示，其余通道就绪后仍可一起播放。返回已查看的片段时，可复用内存缓存中的标定结果；打开其他记录时缓存会清空。

每个**触觉响应**面板只显示一张响应图，保持传感器原始画面的方向。紫色经橙色至浅黄色表示图像响应逐渐增强；黑色表示未检测到响应或不在感知区域内。仅显示感知表面内部的变化。明亮弧线及其周围的保护带会被遮蔽为黑色，避免边缘移动主导显示；画面范围保持不变。未检测到弧形边界时，该面板保持黑色并显示提示，其他通道仍可使用。**弱–强**图例表示相对图像响应，并非实测力或压力。查看器使用起始 2 秒建立固定基线和逐像素噪声估计（可用时至少取 8 帧，短片使用全部帧），然后对变化进行平滑和着色。点击面板的显示设置（滑块图标），可在 1～16 倍之间调整显示增益（默认 10 倍），或开启**显示全部变化**，跳过去噪并显示感知区域内的细微差异和背景噪声，区域遮罩始终生效。伽马固定为 0.7。播放、跳转和展开面板始终使用同一基线与区域遮罩，持续的图像变化不会随时间消失。起始片段中的已有接触可能成为基线的一部分。若触觉图像没有可检测到的变化，查看器不会凭空显示接触。原始记录不会被修改。

查看器会自动使用完整的原始相机时间戳，支持 ARX5 训练数据中有意少一行的时间戳文件。“估算对齐”表示原始和训练时间戳文件均无法为每个视频帧提供有效时间戳，此时使用视频自身的时间信息估算。未记录触觉数值数据时，仍可查看触觉响应图。

点击语言按钮切换中英文。随时可打开其他文件夹或 TAR 文件。

请使用较新的桌面 Firefox、Chrome 或 Edge 浏览器。无需安装插件或额外的视频解码器。开始播放或跳转后，查看器可能短暂显示“正在同步”，以填充解码缓冲区。直接打开压缩包目前支持未压缩的 `.tar` 文件。

如果某个传感器的弧形边界难以检测，查看器还会检查所选文件夹或 TAR 中匹配的相邻片段，无需先手动打开这些片段。仅复用经过图像对齐验证的弧形几何；各片段仍使用自身的基线和噪声估计。将鼠标移到恢复提示上可查看参考片段。选择父文件夹或完整任务 TAR 可提供相邻片段。

## 可选力估算显示

力显示默认关闭。开启“显示估算力”后，查看器会复用匹配的已保存结果，或准备当前
片段的全部触觉帧。计算期间播放暂停，可能需要数分钟；可以取消或关闭此选项，
继续普通 RGB/触觉播放。准备完成后保持暂停，点击播放即可同步查看各传感器的
Fz（正向力）、剪切力大小（单位 N）及曲线。展开视图中也会显示数值。

点击“保存力数据”可分享 `*.rdv-force.json`。接收者可点击“导入力数据”，也可将
文件放在录制文件夹或 TAR 中。查看器按视频内容校验匹配关系，避免同名文件误配。
查看及浏览器计算均不需要 Python 或网络。浏览器计算需要将 `force-runtime.js`
与 `viewer.html` 放在一起；导入已有力数据时无需加载模型。

这些数值是模型估算，并非经过标定的实测力。首帧作为参考，可能已经包含接触；
模型本身也可能存在非零基线。增益及弧形边缘遮罩仅改变热图，不改变力估算。
